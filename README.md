# 🕹️ Java Pac-Man 小精靈遊戲

歡迎來到經典小精靈（Pac-Man）的 Java 專案！本專案使用 Java Swing 進行視窗繪製與事件處理，並實作了基本的地圖載入、小精靈移動與鬼魂機制。

## 🎮 遊戲下載與即玩指南

為了方便快速體驗，本專案已將所有圖形資源與程式碼封裝。你不需要安裝開發工具，即可直接執行遊戲：

1. **下載遊戲**：請至右側的 **[Releases 頁面]** 或直接點擊下方連結下載最新版的可執行檔：
   👉 **[點我下載 PacMan.jar](https://github.com/ChingHui418/Pacman/releases/tag/v1.0.0)**
2. **直接開玩**：下載完成後，在 `PacMan.jar` 檔案上**連點滑鼠左鍵兩下**，即可直接開啟遊戲視窗！
   *(註：電腦需安裝 Java 執行環境 JRE/JDK)*

---

## 🛠️ 技術架構與亮點

本專案著重於 Java 基礎物件導向設計與視窗事件處理的實作：

- **核心語言**：Java (Oracle JDK)
- **圖形介面**：Java AWT / Swing (`JPanel`, `ImageIcon`)
- **遊戲迴圈**：使用 `javax.swing.Timer` 建立事件驅動機制，每 50 毫秒觸發視窗重繪（Repaint）。
- **資料結構與效能優化**：
  - 地圖上的牆壁（Walls）、食物（Foods）與鬼魂（Ghosts）皆由 `HashSet` 進行高效管理。
  - 利用 `HashSet` 具備 $O(1)$ 的高效率尋找特性，大幅優化了遊戲每幀進行大規模方塊碰撞偵測時的運算效能。
- **地圖解析器**：實作二維文字矩陣（`String[] tileMap`）轉譯機制，動態解析字元並渲染成對應的遊戲地圖物件，達成資料邏輯與畫面呈現的分離。

## 📁 專案資料夾結構

- `src/`：存放所有 Java 原始碼（`.java`）以及遊戲所需的圖片資源（`.png`）。
- `bin/`：存放編譯後的位元組碼檔案（`.class`），由系統自動生成。
- `lib/`：存放專案外部依賴庫。

> 💡 **開發備忘**：所有遊戲圖片資源皆必須放置於 `src/` 根目錄下，程式內部使用 `getClass().getResource("/filename.png")` 透過類路徑（Classpath）根目錄進行絕對路徑讀取，以確保資源載入之穩定性。
